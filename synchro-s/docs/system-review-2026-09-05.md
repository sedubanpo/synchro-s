# Synchro-S 안정화 검토 — 2026-09-05

## 범위와 결론

홈·전체 시간표, 학생/강사 시간표, 신규문의 시간표 생성, 수업 편집·복사,
저장 그룹·태그·만료, 명단 동기화, 로그인/권한의 공통 경로를 검토했다.
기존 UI를 유지하면서 확인 가능한 데이터 누락·권한·경합 문제를 수정했다.
모든 운영 데이터 조합을 실사용 계정으로 전수 검사했다는 의미는 아니다.

## 수정 사항

1. 주간 수업·수강생·예외 일정·활성 저장 그룹을 페이지 단위로 읽는다.
   Supabase의 기본 응답 제한으로 1,000건 이후 데이터가 누락되던 경로를 수정했다.
   수강생/그룹 조회의 IN 필터는 100개 ID 단위, 최대 4개 동시 요청으로 제한한다.
2. 강사/학생 계정의 주간 조회는 요청 view 값이 아니라 계정 역할로 범위를 결정한다.
   강사 수업 상태 변경에도 본인 소유 수업인지 서버에서 확인한다.
   서비스 역할 DB 클라이언트를 쓰는 세션은 RLS만으로 소유권을 보장할 수 없다.
3. 비정상 세션 서명은 UTF-8 바이트 길이를 비교한 뒤 검증한다.
   다중 구분자 및 잘못된 만료 시각도 거부한다.
4. Google Sheets 메타데이터와 Firebase 명단을 병렬 조회한다.
   명단 응답 및 학교 로고 보강이 늦게 도착해 최신 명단을 덮는 상황을 방지한다.
5. 전체 태그 복사 미리보기 토큰에 원본 그룹 내용을 포함한다.
   미리보기 이후 원본 수정 시 재확인이 필요하며, 잘못된 목록·태그·날짜 입력도 거부한다.
6. 전체 태그 복사의 중복 클릭을 동기적으로 차단한다.
   실패 시 오래된 실행 버튼을 제거하고 한국어 재시도 안내를 표시한다.
   다이얼로그 종료 시 원래 버튼으로 포커스를 돌리고, 처리 중 Tab 이탈을 방지한다.
7. Next.js/ESLint를 15.5.25로 갱신하고 cookies 및 동적 경로 params를 async API에 맞췄다.
   React 18은 유지했다. undici/PostCSS의 호환 가능한 보안 패치 버전을 고정했다.

## 검증

- `npm run build`: 통과. 타입 및 빌드 내 lint 검사 포함.
- `scripts/*.mts` 28개: 모두 통과. 일부는 소스 계약 검사이며 전부 브라우저 E2E는 아니다.
- 신규 서비스 회귀 검사: 1,101개 수업/수강생/활성 그룹 전체 반환,
  IN 필터 길이 제한, 단일 ID의 다중 결과 페이지, 비정상 세션 복구 확인.
- `npm audit --omit=dev`: 알려진 운영 의존성 경고 15개 → 0개.
  보안 문제가 전혀 없다는 보장은 아니다.
- 로컬 운영 빌드 브라우저: 홈→학생→전체 태그 복사, 미리보기 1명/3개 표시,
  네트워크 실패 후 실행 버튼 없음, 재시도 성공 시 실행 버튼 복구,
  Escape 후 원래 버튼 포커스 확인. 가상 API 응답만 사용했고 실제 일괄 복사는 실행하지 않았다.
- 초기 브라우저 픽스처의 라우팅 순서 때문에 불완전한 options 응답이 전달되어 오류가 났다.
  픽스처 수정 후 정상 렌더링했으며 최종 변경분 테스트에서 새 렌더링 예외는 관찰되지 않았다.
- Impeccable/React 점검: 기존 밀도·색상 체계 유지. 기존 화면의 색 배경 위 회색 텍스트
  경고 7개는 자동 검출 후보로 남겼고, 이번 수정 범위의 기능 오류로 판단하지 않았다.

## 남은 개선 후보 / 검증 한계

- 로그인된 관리자·강사·학생별 실제 운영 DB 쓰기까지의 E2E는 이번에 실행하지 않았다.
  인증 전 운영 접속과 배포 상태 확인은 별도로 기록한다.
- 기존 img 최적화 lint 경고 1개와 Browserslist 데이터 갱신 안내는 남아 있다.
- 광범위한 시각적 재설계, 실제 재원생 일괄 복사, DB 스키마 변경은 하지 않았다.
